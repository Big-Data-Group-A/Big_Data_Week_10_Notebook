## 📊 What Was Done — By Part

### Part 1 — Explore & Split (5 marks)
- Loaded the CSV, printed shape `(150, 9)`.
- Correlation of `score` with:
  - `quiz_avg` ≈ **0.94** ← most useful
  - `assignments_avg` ≈ 0.78
  - `attendance_pct` ≈ 0.27
- Split into **112 train / 38 test** with `test_size=0.25, random_state=42`.

### Part 2 — Regression — Predict the Score (10 marks)
- Fitted `LinearRegression` on 3 features.
- **Coefficient of `quiz_avg` ≈ +0.95** → one extra quiz point ≈ **+0.95 exam points**.
- Test-set metrics:
  - **MAE ≈ 3.3 points** — on average, predictions are within ~3 points of the real score.
  - **R² ≈ 0.89** — the 3 features explain ~89% of score variation.
- Predicted scores for a new student and for an invented personal profile.

### Part 3 — Classification — Catch the At-Risk Students (8 marks)
- Built binary target `passed = (score >= 50)`.
- Trained `LogisticRegression(max_iter=1000)`.
- **Accuracy trap explained via the confusion matrix**: the lazy "everyone passes" baseline gets ~90% accuracy but catches **zero** at-risk students; my model catches most failing students — so it is genuinely useful, even though its raw accuracy looks similar.

### Part 4 — Feature Engineering (5 marks)
- Compared 3 regressions on the same split:
  1. `quiz_avg` only → R² ≈ **0.62**
  2. all 3 numeric → R² ≈ **0.89**
  3. all 3 + `program` one-hot → R² ≈ **0.88**
- **Lesson:** adding *relevant* features helped a lot; adding `program` one-hot encoding slightly hurt — more features ≠ better model when extra features are noise on a small dataset.

### Part 5 — Ship a Dashboard (7 marks)
Three Plotly Express charts, each with a title:
1. **"1. Where the class stands"** — histogram of `score`, 12 bins.
2. **"2. Who is at risk"** — scatter `quiz_avg` vs `score`, colored by `passed`, hover shows `name`.
3. **"3. Where to act"** — bar chart of average score per district.

Saved chart #2 as **`class_dashboard.html`** → opened in browser → screenshot saved.
